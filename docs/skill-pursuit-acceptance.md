# v2.29.0 技能規則、收藏卡與魔王追擊驗收

日期：2026-10-10。限定本次九項需求，題庫、基本攻擊、卡片美術、直式配置與最終關基礎扣血規則維持原設定。

## 實作結果

| 項目 | 新規則 |
| --- | --- |
| 守護城堡／天穹守護城 | 完整抵擋下一次／下兩次命中攻擊，不限傷害；主角不扣血。落空不消耗護盾。反擊傷害不變。 |
| 千鏡破偽陣 | 下兩次魔王攻擊各判定一次 50% 落空，不在同一次攻擊重抽。初階鏡系不變。 |
| 極寒冰龍 | 下兩次命中攻擊減半；落空不消耗。先減半，再計算城堡抵擋。初階冰系不變。 |
| 智慧烈焰鳳 | 進階最終魔王每個完成回合燃燒 6 HP；其餘關卡仍 4 HP。重試不額外觸發。 |
| 萬卷雷霆陣 | 下一題與再下一題各有兩個雷光選項；重試同一題不消耗第二題。初階雷系不變。 |
| 收藏卡 | 類別與等級徽章同高、同行；同列升級說明、技能說明與收藏狀態對齊。 |
| 桌機戰鬥 | 共用橫式 60% 戰鬥／40% 讀題版型，特效按左側戰鬥區縮放；直式不變。 |
| 初進階十二隻關卡魔王 | 第二次及之後連錯攻擊追加 10 HP，基礎 12 HP 合計 22 HP；答對重設連錯，逾時不觸發追擊。最終魔王既有 30 HP 不變。 |

追擊依各魔王使用鎖鏈、書頁、分類印章、面具碎片、紙翼、齒輪、蛛網、沙漏、藤鞭、尾影、墨滴及雲拳。聚能、飛襲、材質撞擊與追加追擊使用同一段 2.05 秒演出，不追加題目等待時間或重複扣血。完整擋傷與落空不播放命中撞擊，並保留正確護盾／閃避提示。
