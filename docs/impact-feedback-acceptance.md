# v2.31 雙方命中聲與震動驗收

本版僅補強命中音效、角色受擊及戰場震動；題庫、傷害、計分、60/40 排版與自動換題規則不變。

## 命中聲

- 提高雙方普通攻擊、必殺與魔王追擊的命中增益，加入短重擊、裂響和低頻餘震，保留各元素的材質聲與使用者提供的樣本。
- 普通攻擊的背景音樂仍為原音量的 25%；落空、全格擋、蓄力及朗讀混音不提高。
- 相對 v2.30，以真實 OfflineAudioContext 渲染 224 種組合，分別使用 44.1 kHz、48 kHz，共 448 組；涵蓋雙方、兩級、六主題、最終魔王、普通／強化、已載入樣本／合成回退與減少動態。

| 測量 | 44.1 kHz | 48 kHz |
| --- | ---: | ---: |
| 命中段平均 RMS 比率 | 1.699 | 1.715 |
| 命中段最低 RMS 比率 | 1.303 | 1.290 |
| 最大峰值（滿幅為 1） | 0.948 | 0.960 |
| 削波／非有限樣本／換題後殘音 | 0 | 0 |

RMS 是訊號強度，不代表人耳主觀音量同比增加。蓄力與非命中波形對舊版的差異不超過 2×10⁻⁹。

## 受擊表現

- 接觸點保持 900ms；戰場震動 360ms，普通峰值 8px、必殺／追擊 12px，衰減歸零；角色受擊姿態 470ms 內收束。
- 依實際角色投影、震動位移與縮放限制邊界，不改待機大小。修正新增後退幅度在窄畫面造成主角裁切的問題。
- 以真實新姿態取代舊 framing 測試的位移；獨立投影複驗 328×320、589×683、1114×958 戰鬥窗、初／進階與最終魔王，最小左右留白約 14px。
- 手機震動在接觸點觸發一次，普通 100–140ms、強化 210–240ms。零傷害、落空、完整格擋及減少動態不觸發；離場、換題、隱藏頁面與卸載都取消。

## 實際網頁驗收

使用獨立 localhost 測試存檔，不修改正式站學生進度。

| 案例 | 結果 |
| --- | --- |
| 主角普通命中 | 魔王扣 25 HP，震動目標為 enemy，演出後自動進第二題 |
| 魔王普通命中 | 主角 100→88 HP，震動目標為 hero，保留重試 |
| 魔王連錯追擊 | 主角 88→66 HP，強化震動一次，保留重試 |
| 全格擋／鏡界落空 | 不扣血、無受擊震動及裝置震動 |
| 減少動態 | 無震動，仍自動換題 |
| 音效關閉 | 受擊視覺與裝置震動仍正常，音效偏好不變 |
| 命中前離開 | 返回封面，取消尚未開始的震動 |
| 進階火鳳必殺 | 強化震動一次，保留召喚物，演出後進第五題 |

已於 390×844、844×390、768×1024、1024×768、1280×800 驗收魔王追擊：各次命中有震動並收束，沒有橫向溢位；震動期間 HP 列與答案區的 x/y 位移均為 0。

瀏覽器驗收攔截並記錄 Vibration API 呼叫，未宣稱實體手機馬達測試；實際震動取決於裝置與瀏覽器支援。無支援時保留戰場視覺震動。
