# 協會品牌與十二張收藏卡排版驗收

版本：2.22.0，2026-10-09。

## 品牌

- 使用提供的 AI 原件直接轉成 SVG，保留原彩色圖形及已轉外框的中英文名稱，沒有重繪。
- 首頁放在主文案上方；冒險地圖、成長、設定及成績頁共用內容頂端的淺色品牌牌面。
- 戰鬥介面不增加品牌區塊，以免影響題目與血量。
- 1280 × 720 實際封面驗收：Logo 為 420 × 99.7 px；開始按鈕 y561.7–623.7，完整可見。
- 手機以同來源的 390 × 844 iframe 載入真正遊戲頁面驗收 CSS 媒體條件：首頁及主頁標誌等比縮放，無橫向溢出。IAB 的 viewport override 沒有改變實際尺寸，因此沒有以該功能的回傳作為驗收依據。
- SVG 已列入完整離線資產清單。

## 收藏卡

- 根因：不同畫作的名稱牌框高度不一致，但舊版共用文字座標；SVG 與 PNG 的基線規則也不同。
- 十二張卡逐張指定牌框安全區及字級。收藏列表、放大視窗及 PNG 下載使用同一份座標與 alphabetic 基線。
- 下載前明確等待名稱所需的 Noto Sans TC 字形載入，避免字形替換造成排版差異。
- 已使用正式的 PNG 合成函式產生並目視檢查全部十二張；每個名稱皆在牌框內並留有邊界。
- 初階：守護城堡、雷霆索引、萬葉歸位、鏡界破偽、智慧火鳳、寒晶冰矛。
- 進階：天穹守護城、萬卷雷霆陣、森羅歸位界、千鏡破偽陣、智慧烈焰鳳、極寒冰龍。
- 正常操作放大「萬葉歸位」，並下載 1024 × 1536 PNG，確認畫面與圖檔排版一致。
- 390 px 手機放大「森羅歸位界」：dialog 寬358 px，內容 scrollWidth/clientWidth 均339 px，無橫向溢出。
- 題目、故事、傷害、能量、收藏條件、分數及既有進度均未改動。
