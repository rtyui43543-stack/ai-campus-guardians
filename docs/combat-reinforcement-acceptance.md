# 主角與魔王攻擊補強驗收

2026-10-10，v2.26.0。

本次依已核准的方案補強普通攻擊、魔王施法與聲音層次。題庫、作答、分數、收藏解鎖、魔法附加效果、背景曲目與角色原圖不變。初階六關仍為四題／25 HP，進階六關五題／20 HP；最終魔王仍為 200／300 HP。

## 演出

主角六種普通攻擊使用較大的主投射物、較小的伴隨物、接觸前加速與局部材質落點：城堡鎖印、雷霆書頁、葉片拼圖、鏡刃、火羽與冰矛。受擊反應在接觸後維持 75 ms，再回復原位；不凍結遊戲或音效時鐘，不晃動攝影機。

初階魔王分別以鎖鏈、書頁、印章、面具、紙翼與齒輪施法；進階魔王分別使用蛛網、沙流、藤鞭、狐影、墨滴與雲拳。加入可見蓄勢、出手、材質撞擊與收勢，並顯示實際魔王招式名稱。

最終魔典王追擊增加巨書張開、符文扇頁和破裂封陣；九頭龍使用正立朝左的九首幻影與匯聚幻焰。角色沿用原圖，透過可見圖像幾何壓縮、前傾和九頭聚能補足動作，沒有把同一圖稱作新製作的四張動作圖。主角所有必殺區塊未修改，進階火鳥與冰龍維持原演出。

普通及敵方追擊演出維持 2.05 秒，480 ms 出手、900 ms 接觸；主角必殺維持 3 秒，保留原本 420 ms 出手軌跡及角色反應。減少動態使用短時固定招式形體。護盾落在盾面，閃避落在角色身旁；完全擋住或閃避不切主角受傷圖，部分減傷仍顯示實際受擊。

新魔王演出使用攝影機投影的角色位置，裁切在題目與選項之間的安全範圍。傷害數字置於角色下方，避免擋住頭部；普通施法保留選項、必殺隱藏上下文字，重新作答或下一題恢復。

## 音效

以短起音、短維持的撞擊包絡、中頻重量、材質尾音與左右聲像移動建立聲層。六個既有素材以適合各招式的短片段及濾波融入；合成聲保留素材尚未準備好時的備援。火鳥叫聲、冰龍咆哮等主角必殺音效沿用，未提高共用總增益。

實際瀏覽器觀察普通施法時背景音量由 0.27 降到 0.0675，為原音量的 25%，特效結束後恢復。換題、重試、返回首頁、關音效與頁面隱藏均停止現行音效、取消未播放音源並釋放配樂壓低狀態。

## 驗證與限制

- 全套 761 項自動測試通過（759 項 Vitest、2 項 Node），涵蓋戰鬥規則、施法幾何、角色姿勢、時序、減少動態、防禦／閃避、資源回收、音效包絡、素材替換及取消播放。
- 360×800、390×844、768×1024、1024×768、1440×900 的投影矩陣驗證十二個普通魔王與兩個最終魔王實際動作，均保留既有角色安全窗口與固定鏡頭。
- OfflineAudioContext 直接執行正式 audio.ts 的 86 組混音（普通、必殺、追擊、防禦、閃避、減少動態），全部數值有限、削波樣本 0，最高峰值 0.599762，截止後峰值 0；六種 MP3 素材均實際使用。這是 PCM 驗證，不冒稱已經學生實聽。
- 正式 Three.js 招式在固定鏡頭直接渲染 22 組／44 張飛襲與命中圖；全部形體可見、幾何範圍有限，單次招式最高 125 draw calls／19,360 triangles。這不等同實體低階平板的 FPS 基準。
- 手機、平板直式／橫式在隔離瀏覽器驗收實際 App。證據與原始數據保存在被忽略的 test-results/combat-reinforcement-review，不公開測試存檔與驗收頁。
- 內容檢查維持 84 題、1,704 個朗讀鍵、1,326 個朗讀檔，無內容錯誤；TypeScript、正式建置、離線包與 GitHub Pages 子路徑檢查通過。

此處裝置檢查為瀏覽器尺寸模擬與幾何投影，尚未代替學生使用的實體手機、平板喇叭與操作測試。
