日期：2026-10-07。正式版本：d7480aa3158e408ac3273212b6e2e1d5ae95268f3fe5c87842f8f92aa6ced7dd。

## 已完成

- 原始碼附 GitHub Actions 建置／部署；另提供可直接發布的靜態網站包。
- 網站使用相對路徑，支援任意 GitHub Pages 專案子路徑，無需填入帳號或儲存庫名稱。
- 首頁及設定頁共用離線下載卡，顯示檔案數、百分比、已下載／總容量，支援暫停與接續。
- 加入主畫面、完整下載、飛航模式重開及移除後重新下載的說明均在遊戲內。
- 全部726個離線檔案共44,845,753 bytes（約42.8 MiB）；包含606段預錄中文語音。所有檔案通過SHA-256與大小檢查，113個HTML／CSS素材連結通過專案路徑檢查。
- 初階六關、進階六關與84題題庫保持完整；教師CSV、HTML、Markdown與JSON同步。

## 自動驗證

83項Vitest測試與2項Node預覽服務測試通過，共85項。TypeScript、正式建置、題庫及606段語音檢查通過。

新增驗證涵蓋：GitHub專案路徑的離線導航與MP3範圍讀取、不同專案快取隔離、暫停後工作／頁面重開及續傳、重複下載工作避免、暫停狀態不被新核心包覆蓋，以及舊版未快取音檔被新發布移除時的新版復原流程。新版完成後需明確套用，再重新開啟；不會在作答中切換題庫版本。

## 實際瀏覽器操作

本機預覽服務嚴格模擬 `/ai-campus-guardians/`：根網址與根素材網址回傳404，只有專案子路徑提供遊戲，因此無法靠根目錄回退掩蓋路徑錯誤。

正式版本在300／726個檔案、53%時暫停。重新載入後仍顯示「已暫停」、300／726與53%；按繼續下載後完成726／726與100%，顯示「可離線使用」。

停止本機網站服務並確認HTTP連線遭拒後，重新載入仍成功開啟首頁。離線進入第一關，3D渲染為three-webgl；中文MP3正常播放（readyState=4、paused=false、currentTime>3秒、沒有媒體錯誤）。答對後敵方100→80 HP；再次重新載入仍保留80 HP與成功回饋，沒有重複攻擊。全部素材和存檔均來自本機快取。

畫面證據：test-results/github-offline-preview.jpg。資料證據：test-results/v2-github-pages-static-audit.json、v2-github-pages-browser-audit.json與github-tests.log。

## 尚待實際發布與裝置驗收

尚未發布到使用者的遠端GitHub儲存庫。GitHub Pages網址取得後，仍需在實際iPhone／iPad／Android裝置，從加入主畫面的App完成下載，再以飛航模式關閉／重開驗證。瀏覽器視窗尺寸檢查不代表實機安裝驗收；學生試玩亦尚待進行。

離線資料按裝置及瀏覽器保存。清除網站資料、移除App或瀏覽器清理儲存空間，可能移除離線素材與進度，需重新下載；進度可先匯出備份。
