# v2.32 命中速度與爆發力驗收

本版只修改雙方戰鬥音效及版本號。題庫、傷害、計分、60/40 排版、角色演出、震動與自動換題規則維持 v2.31。

## 調整

- 命中前 110ms 加入加速、跨聲道的破風聲，900ms 接觸點立即播放裂響，14ms 後接短重擊與碎裂聲。
- 新增接觸聲層於 1078ms 內收束，減少拖尾低鳴；在接觸瞬間提高輸出增益，隨後回復。魔王追擊第二接觸點也有相同強化。
- 使用者提供的重物與爆炸樣本改為快速前緣與自然衰減；鳳凰叫聲、冰龍咆嘯和飛行素材維持原包絡。已載入樣本仍保留新破風與接觸層，未載入時保留合成回退。
- 傷害命中才啟用峰值保護；曲線保留 0.9 以下訊號並柔化更高峰值。無重取樣，避免重建濾波過衝。落空與完全格擋沿用原聲音。
- 普通攻擊背景音量維持原音量的 25%；必殺／追擊沿用原降音幅度，音效不延長戰鬥或換題。

## 新舊音訊量測

以 v2.31（ae73b4f）為基準，使用真實 audio.ts 與 OfflineAudioContext，每種取樣率各 224 組，共 448 組。涵蓋雙方、初進階、六主題、最終魔王、普通／必殺／追擊、已載入樣本／合成回退、減少動態及落空／格擋。

下表接觸窗為正常演出的前 100ms；手機可辨識頻段以 500–4000Hz 濾波量測，並非實體手機喇叭測試。

| 測量 | 44.1 kHz | 48 kHz |
| --- | ---: | ---: |
| 接觸窗 RMS 新／舊範圍 | 1.120–1.553 | 1.041–1.515 |
| 500–4000Hz 接觸窗 RMS 新／舊範圍 | 1.187–1.602 | 1.147–1.526 |
| 最大峰值（滿幅為 1） | 0.9742 | 0.9739 |
| 削波／非有限樣本／跨題殘音 | 0 | 0 |

RMS 描述訊號強度，不代表主觀音量同比增加。減少動態演出壓縮為六分之一，少數極短接觸窗 RMS 較前版低，但前緣更明顯，保留短促演出；不以延長尾音追求整窗數值。落空／完全格擋差異低於 2×10⁻⁹。

## 實際網頁驗證

使用獨立 localhost 存檔、真實 AudioContext 輸出分析與 DOM 記錄，不修改正式站學生進度。

| 案例 | 結果 |
| --- | --- |
| 初階火羽普通命中 | 魔王 100→75 HP；背景音量 0.27→0.0675→0.27；演出後自動進第二題 |
| 進階雲巨人普通攻擊 | 主角 100→88 HP；命中聲與受擊震動觸發，保留重試 |
| 進階雲巨人連錯追擊 | 主角 88→66 HP；雙段音效，保留強化震動與重試 |
| 進階冰龍必殺 | 保留冰龍演出及強化震動；魔王 40→5 HP，自動進第五題 |
| 音效關閉 | 實測輸出為 0，仍正常震動與自動換題 |
| 命中前離場 | 返回封面；聲音於約 247ms 前收束，無延遲命中或震動 |

上述普通攻擊、追擊與必殺的音效均在原演出期限前收束，背景音樂正常回復。Vibration API 為瀏覽器呼叫記錄，未宣稱實體裝置馬達測試；本版未更改其實作。
