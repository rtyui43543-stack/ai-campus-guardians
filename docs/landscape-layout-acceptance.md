# 手機與平板橫式介面驗收

2026-10-10，版本 2.27.0。依核准的橫式改善方案執行。本文件區分瀏覽器尺寸驗收、自動測試及仍需實機確認的範圍。

## 修改範圍

- 手機短橫式使用緊湊血量／題數列、左側約 40% 的獨立戰鬥視窗、右側約 60% 的閱讀與四選項區。高度不足的平板橫式使用約 45%／55% 分欄。移除超過可用高度的最小高度；長提示與放大文字在閱讀區捲動，保留全文。
- 較高的平板橫式維持上下閱讀順序：狀態列、題目、較大的戰鬥視窗、2×2 選項與控制。預留演出後解說按鈕的空間，避免人物在出招前後突然縮小。
- 題目先於能量、音樂等輔助資訊；朗讀按鈕顯示「朗讀」，暫停倒數提示可換行。必殺就緒與長選項不互相擠壓。
- 招式名稱、投射物、命中位置與扣血數字使用戰鬥視窗座標；角色大小依實際可用空間計算。旋轉時重新取景，已射出的招式起點跟隨施法者位置。
- 劇情橫式使用左場景、右字幕與 2×2 控制。圖示在人物場景下方的獨立帶內，短手機橫式約 52 px、平板約 56 px。字幕完整換行；極小畫面或大字使用字幕區捲動備援。
- 橫式主要控制保留至少 44 px 高度及安全邊距。直式與大型桌機沿用原版排版。

本次不修改題庫、故事與朗讀內容、計分、扣血、收藏與解鎖、人物原圖、技能圖像、音樂或音效素材。初階六關仍為四題、普通攻擊 25 HP；進階六關五題、20 HP；最終魔王 200／300 HP。普通攻擊背景音維持原音量的 25%。火鳥與水龍原圖及演出時序保留。

## 互動與演出證據

- 普通攻擊時題目隱藏、選項保留；演出後解說及下一題可操作，下一題恢復文字。實際驗收初階敵方 HP 100→75；背景音音量 .27→.0675→.27。
- 進階火鳥必殺時上下文字均隱藏；出招途中由橫式旋轉為直式，畫布重新取景、扣血一次，演出後解說與下一題可操作。
- 最終九頭龍連錯追擊顯示專屬演出；驗收我方 HP 80→50，重試後題目與選項恢復。減少動態設定仍可完成施法與後續操作。
- 長提示使用閱讀區捲動，收起提示後恢復；朗讀時倒數暫停。劇情三幕切換、長字幕、控制與獨立圖示帶通過檢查。
- 160 項取景測試涵蓋十二個普通對手、兩個最終魔王、施法／受擊／閃避、旋轉與投射物起點。專用窄畫面中的實際人物圖集投影：主角最小約 111 px（328×320）、160 px（450×532）、230 px（992×323）；等待時雙方輪廓間距至少 8 px。

驗收截圖及 DOM 觀察記錄放於本機忽略目錄 `test-results/landscape-layout-review/`，含手機長題、平板讀題、普通攻擊、火鳥旋轉及各尺寸劇情畫面。

## 自動驗證與限制

- `npm test`：50 個 Vitest 測試檔、828 項測試，加 2 項 Node 預覽測試，全數通過。
- `npm run content:check`：題庫、題數與預錄朗讀檢查通過，錯誤零項。
- `npm run build`：TypeScript、正式建置、教材匯出與 GitHub Pages 靜態資源檢查通過。
- 離線包：1498 個檔案、1334 個音訊檔；Pages 路徑、音訊範圍請求與 Service Worker 範圍通過檢查。

以上是瀏覽器視窗尺寸模擬及程式驗證，不等同實體手機、平板的觸控、系統工具列、音效體感或效能測試。正式上線後另比對線上 JS／CSS 與本機正式建置、題庫、朗讀索引及離線版本；實機直橫式試玩仍應由使用者裝置確認。
