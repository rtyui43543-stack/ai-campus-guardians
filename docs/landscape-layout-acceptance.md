# 手機與平板橫式介面驗收

2026-10-10，版本 2.28.0。依核准的「橫式戰鬥 60%／題目與選項 40%」預覽方案執行，並檢查火鳥與進階冰龍召喚圖顯示問題。本文件區分瀏覽器尺寸驗收、自動測試及仍需實機確認的範圍。

## 修改範圍

- 手機與平板橫式統一使用緊湊血量／題數列、左側 60% 的獨立戰鬥視窗、右側 40% 的題目與四選項區。比例以頂部血量列下方的內容區計算，扣除內距與兩欄間隔；直式與大型桌機沿用原排版。
- 右欄題目保持在頂部，四選項使用 2×2 排列。長選項可在選項區捲動，提示及大字超出題目區時使用題目區捲動，保留全文。底部操作與演出後解說可達，不因長文字縮小或移動左側戰鬥視窗。
- 題目先於能量、音樂等輔助資訊；朗讀按鈕顯示「朗讀」，暫停倒數提示可換行。必殺就緒與長選項不互相擠壓。
- 招式名稱、投射物、命中位置與扣血數字使用戰鬥視窗座標；角色大小依實際可用空間計算。旋轉時重新取景，已射出的招式起點跟隨施法者位置。
- 劇情橫式使用左場景、右字幕與 2×2 控制。圖示在人物場景下方的獨立帶內，短手機橫式約 52 px、平板約 56 px。字幕完整換行；極小畫面或大字使用字幕區捲動備援。
- 橫式主要控制保留至少 44 px 高度及安全邊距。直式與大型桌機沿用原版排版。
- 火鳥（初階、進階）及進階冰龍沿用既有原圖，檢查召喚圖片載入、重試與失敗備援。資源載入修復及完整施放實測結果待最終驗收補入。

本次不修改題庫、故事與朗讀內容、計分、扣血、收藏與解鎖、人物原圖、技能美術、音樂或音效素材；召喚圖修復僅處理既有圖片的載入與顯示。初階六關仍為四題、普通攻擊 25 HP；進階六關五題、20 HP；最終魔王 200／300 HP。普通攻擊背景音維持原音量的 25%。火鳥與冰龍原圖及演出時序保留；劇情圖示帶延續 2.27.0，不在本次另行改版。

## 互動與演出證據

- 本次沿用的互動驗收要求：普通攻擊題目隱藏、選項保留；必殺時上下文字隱藏；演出後解說、重試或下一題可操作；下一題恢復文字。出招前後與捲動選項時戰鬥視窗保持穩定。
- 三種召喚在暖快取中原本可正常顯示，未宣稱重現所有使用者裝置的消失情況；檢查發現預載未保留 Image，且解碼失敗也會被當成就緒。現已保留解碼成功的原圖，未就緒時使用隨程式內嵌的同張透明縮圖，圖片失敗可重試。每次施放固定圖源，沒有中途換圖、重畫怪物或延長出招。
- 在隔離驗收頁將原圖預載延遲 8 秒，實際施放初階火鳥、進階火鳥及進階冰龍：250／650 ms 的圖片均完成載入、自然寬度 512 px、圖層可見；截圖確認完整怪物輪廓。熱載冰龍另確認使用自然寬度 1536 px 的原 PNG。下載與解碼失敗備援另有自動測試。
- 本版普通攻擊驗收敵方 100→75 HP，背景音 .27→.0675→.27；必殺演出背景音 .014、結束恢復 .27。進階火鳥與冰龍 40→5 HP 僅結算一次，初階火鳥 25→0 HP；演出後即時解說、下一題或完成挑戰可操作。
- 減少動態的冰龍施放途中旋轉成 390×844，怪物圖仍顯示，40→5 HP 僅扣一次；下一題恢復讀題與四選項。568×320 連錯後重試／伙伴示範、解說與提示收合均可操作，控制不再單字直排。844×390 朗讀暫停倒數正常。九頭龍上版 80→50 HP 演出與扣血邏輯未修改。

## 自動驗證與限制

- `npx vitest run src/components/arenaFraming.test.ts --maxWorkers=1`：220 項通過。
- `npm test`：50 個 Vitest 檔、895 項測試，加 2 項 Node 預覽測試，合計 897 項全數通過。精確視窗尺寸調整後的 220 項取景測試另重跑通過。
- `npm run content:check`：題庫、題數與 1704 個朗讀鍵檢查通過，錯誤零項。
- `npm run build`：TypeScript、正式建置、教材匯出與 GitHub Pages 靜態資源檢查通過。
- 離線包：1498 個檔案、1334 個音訊檔、約 151.4 MB；原召喚 PNG 已收錄，透明備援直接包含於 JS，不需額外圖片請求。Pages 路徑、音訊範圍請求與 Service Worker 範圍檢查通過。

以上是瀏覽器視窗尺寸模擬及程式驗證，不等同實體手機、平板的觸控、系統工具列、音效體感或效能測試。正式上線後另比對線上 JS／CSS 與本機正式建置、題庫、朗讀索引及離線版本；實機直橫式試玩仍應由使用者裝置確認。
