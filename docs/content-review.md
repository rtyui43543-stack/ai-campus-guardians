# 十四關現行題庫內容複核

2026-10-09；現行來源src/content/question-bank.json。十二個主題關各五題、兩個最終關各十五題，共90題。舊24題複習封存在legacy-review-bank.json，只供歷史紀錄查詢；舊30題複製型最終題封存在legacy-final-bank.json，只供既有場次續玩與歷史查閱，兩者都不提供新開挑戰。初階與進階皆直接選四個選項之一；進階增加情境限制，不另設理由選擇畫面。

| 主題 | 初階 | 進階 |
|---|---|---|
| 個資守護 | 個資小盾牌 | 分享前多想一步 |
| 答案查證 | 答案找線索 | 查證不只看一眼 |
| 情境分類 | 用法分一分 | 分類也要顧公平 |
| 深偽查證 | 聲音影像別急信 | 真假訊息追追追 |
| AI與作業 | 作業自己來 | 學習誠實挑戰 |
| 人與AI合作 | 生活合作隊 | 校園AI守護約定 |

案例使用故事推薦、帳號、同學照片、班級公告、科學報告、AI整理筆記和班級活動等生活情境。題幹上限70字元、選項上限30字元；答案位置涵蓋A–D，沒有固定字母。進階第6主題關Q3接受兩種完整合理的替代方案，任選一種可過。

資料用途、同意與分享範圍皆具體說明，不教成所有資料都不能用。AI辨識或分類錯誤不歸咎於同學，也不以性別決定興趣。查證優先原始、相關、有效日期的來源，AI的肯定語氣不是證據。深偽查證不把奇怪嘴型、逼真外觀、觀看人數或偵測器結果當成定論；以原本熟悉的班級／家庭管道核對，不鼓勵公開指控。

作業案例以老師的規則為前提，區分提供提示、檢查理解與直接代寫；允許合適協助，但要求自己學習、查核並誠實說明。AI編造的書目仍需核對，不能改造作者姓名掩飾。

第二輪逐題複核修正V2L01Q01：「不用告訴它」可能包含可選的興趣資料，改為問「哪一項和找故事沒有關係」，正確答案仍是住址。另修正四處繁體用字；CSV/HTML/Markdown與語音已同步更新。

教材《生活中的人工智慧》（2020）提供辨識、分類、學習應用及協作背景；深偽、生成式AI作業誠信、資料最少化與公平明確標為倫理延伸，不宣稱教材已包含它們。深偽題的單元三頁碼僅對應聲音辨識背景。教師題表列每題來源標籤、單元與印刷頁碼。

倫理延伸參考UNESCO人工智慧倫理建議、UNESCO生成式AI教育研究指引及CISA合成媒體來源查證資料，詳細連結附於正式JSON和教師題表。所有案例為虛構離線學習模擬，沒有蒐集真實兒童資料，學生不需要登入真實AI服務。

每個錯誤選項有針對性回饋，答錯可提示與重試。示範題保留獨立理解紀錄，教師可安排生活應用討論；不以速度或扣血結果替代學習紀錄。仍需真實學生試玩確認閱讀和理解。

最終兩關分別對應初階與進階，各15題為獨立新生活情境，ID為V3F13Q01–15、V3F14Q01–15，不沿用前面60題或copiedFrom。themeId保留學習主題；兩組主題分布均為3、3、2、2、2、3題。逐題情境差異與答案對照見[最終新題複核](final-question-review.md)。初階最終關魔王200HP、進階300HP，題目用盡仍未擊敗則失敗，HP歸零可以提早結算；分數僅按已完成題目正規化為100，不補寫未答紀錄。

2026-10-10，v2.24：現行90題改為V4版，每個選項均含做法與理由，仍然一題一選、立即出招。加入同學社團取名、讀劇腳本、紙風車實測、地方問卷等不同生活情境；保留原學習目標、教材來源、答案位置、題數及戰鬥規則。逐題覆核題幹、360個選項及回饋、提示與解析，並以「同做法、不同理由」確認錯誤理由會被判錯。教師指引以新情境的判斷及所需協助觀察理解程度，不將固定題最高分單獨視為學會。

改版前90題封存於legacy-reasoning-bank.json，舊存檔續玩、匯入及成績重建各自使用完整原版，不以新選項解讀舊選答。原906個朗讀鍵與音檔映射全部保留，新630個鍵與最新文本同步；1,326個音檔皆通過解碼。636項自動測試、內容檢查、Pages及離線包建置通過。手機360×800、390×844與平板768×1024、1024×768實際檢查題目、理由選項、即時解說及朗讀。新版手機選項的字母徽章改為行內顯示，後續行使用整格寬度，保留字級與人物安全區；38.256秒題目朗讀期間剩餘22秒維持暫停，結束後接續倒數。

## 2026-10-10：初階六關改為四題

現行題庫改為84題：初階六個主題關各4題（24題），進階六個主題關各5題（30題），最終兩關各15題（30題）。每個初階主題關移除一題較難立即理解的情境；保留題目、選項、回饋、提示與解析的原文，重新依序編為V5L01Q01–04至V5L06Q01–04。進階V4L07–12與最終V4F13／14的題目及答案沿用原版。

初階主題普通攻擊25HP，四次答對可完成100HP的主題魔王戰；前三題累積三點能量，第4題自己答對仍可施放必殺並取得收藏卡與10點獎勵。四題基本分各最高25分，錯答一次扣5分、自己答對最低5分、用提示最高20分、示範0分；進階五題與最終關計分及傷害維持既有規則。

V4初階五題共30題另存於legacy-five-question-bank.json。五題版途中存檔繼續使用原題序、每次20HP攻擊及原計分，舊成績不按新版四題回溯重算；重開關卡才套用新版。語音索引增至1,704個鍵，1,326個既有MP3保留且復用，確保新版與封存場次各自對應正確朗讀。原有內容複核及驗收段落保留，代表當時版本的紀錄。
