# v2.30.0 直接進關、自動接題與命中音效驗收

日期：2026-10-11。範圍限於進關流程、答對後接題與命中音效；題庫、傷害、技能規則、收藏、60／40 橫式與直式配置不變。

## 行為

- 地圖、成長與結算頁的關卡入口直接開始第一題，不再播放關卡劇情或顯示「任務準備完成」。首頁開場故事保留。
- 自己答對（包含提示或重試後答對）後，普通攻擊約 2.05 秒、必殺約 3 秒演出結束便自動接題；減少動態模式沿用 450／550 毫秒。末題或最終魔王歸零時自動結算。
- 答錯仍可重試及閱讀解說；伙伴示範仍保留原有閱讀停留。答對解說可在結算的逐題紀錄查看。
- 離開對戰取消演出計時器，續玩已答對的存檔時只接題一次；背景頁面不自動接題。新題才啟動新倒數，最終關選必殺技時仍暫停倒數。
- 雙方命中的合成層、撞擊與爆炸取樣增益提高 30%，另增加 160 毫秒中頻撞擊層。蓄力、飛行、吼叫、背景配樂及閃避／完整防禦音量不變；既有音訊限幅與普通攻擊配樂降至 25% 保留。

## 自動檢查

- `npm test`：51 個 Vitest 檔案、997 項測試，另 2 項 Pages preview 測試，共 999 項通過。
- `npm run content:check`：84 題、14 關、1704 個朗讀鍵、1326 個朗讀檔完整，題庫沒有改動。
- `npm run build`：TypeScript、教師手冊、正式建置、離線封裝與 Pages 檢查通過。
- 瀏覽器 OfflineAudioContext 實際渲染新舊音效 224 組，涵蓋雙方普通攻擊、主角必殺、魔王追擊、兩個最終王、取樣／合成備援與減少動態。平均命中 RMS 為原先 1.264 倍、最低 1.111 倍；最大 PCM 峰值 0.823，無削波、非有限值或跨演出時長殘音。落空／完整防禦與命中前音量差近零。

## 真實 App 操作

使用僅限 localhost 的測試入口準備狀態，再透過瀏覽器按鈕操作真實 App；不修改正式網站使用者存檔。

| 案例 | 結果 |
| --- | --- |
| 地圖初階第 2 關 | 點入口直接顯示第 1 題；無關卡故事或準備對話框。 |
| 初階完整四題、含一次答錯 | 正確作答自動接題；錯答仍停同題。第 4 題雷霆必殺後自動結算，4 筆紀錄、1 次結算、95 答題分＋10 必殺分。 |
| 結算頁「前往初階第 3 關」 | 直接出現第 1 題。 |
| 進階第 5 關火鳳必殺 | 第 4 題必殺後自動出第 5 題，倒數重設 30 秒；末題答對自動結算，5 筆紀錄、100＋10 分。 |
| 進階逾時 | 原有超時攻擊與自動接題／結算維持。 |
| 普通攻擊中回首頁、續玩 | 回首頁不跳題；續玩從已答對題接到下一題一次，紀錄與得分不重複。 |

| 初階最終關提前擊敗 | 第 9 題結束即自動勝利，保存實際 9 題，不補滿 15 題。 |
| 進階最終關第 15 題 | 自動勝利結算，100 答題分＋30 必殺分，15 題、三次必殺。 |
| 示範完成存檔 | 仍保留解說及手動接題；之後自行答對恢復自動接題。 |
| 手機與平板 | 390×844、844×390、768×1024、1024×768、1280×800 操作驗收；新題與四個選項恢復、可作答。抽查的手機橫式 492／328、桌面 744／496 像素，維持 60／40。 |
