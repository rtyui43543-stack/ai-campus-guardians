# 初階寒冰必殺與版面驗收（2.16.0）

- 初階第六關新增冰晶召喚陣、單支巨型切面冰矛、命中爆碎冰與擴散霜浪；普通冰矛與進階冰龍保持原有分支。命中時間仍為 0.9 秒，必殺總長 3 秒。
- 325 項 Vitest、2 項 Pages 預覽測試通過；題庫與朗讀完整性檢查、TypeScript、正式建置及 Pages 子路徑檢查通過。
- 本機瀏覽器實際施放初階冰矛必殺：敵方 40 → 10 HP，答題 80＋必殺 10＝總分 90。冰晶碎片及霜浪明顯覆蓋較大範圍，題目與答案保持在特效上方。
- 以實際計分流程產生 88＋10＝98 分結算備份；加分與總分數字皆為 22px／33px 行高，瀏覽器量測兩者 top／bottom 完全相同。
- 390×844 窄螢幕檢查：總分在獎勵區內分行顯示，頁面沒有水平溢出；測試後還原瀏覽器尺寸。
- 冒險地圖沒有下載檢查卡；封面及設定页各自保留下載功能。主頁保留簡短離線提示與設定導覽。
- 正式離線包共 801 檔、648 音訊、87.1 MiB，教師資料未加入學生離線包。下載／套用完整新版後關閉本機 Pages 伺服器，重新載入仍能開啟地圖及封面下載管理介面。
- 減少動態模式保留靜態巨矛、冰晶與霜浪；玩法、傷害、能量、加分、題目、答案與存檔結構未更動。
