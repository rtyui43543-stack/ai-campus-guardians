## 編修方式

修改 src/content/question-bank.json 的 prompt、choices、correct、hint、explanation。correct 使用 0=A、1=B、2=C、3=D。保持 ID、levelId、slot 的對應關係；最終題使用 V3F13Q01–15、V3F14Q01–15 並保留 themeId 學習主題，必須是獨立新情境。歷史複習封存在 legacy-review-bank.json，舊 V2L 最終題封存在 legacy-final-bank.json；兩者都不能作為新開挑戰題目。

修改後執行 npm run content:export、npm run audio:manifest、npm run audio:generate，更新語音後執行 npm run content:check、npm run build。這份 CSV 與 HTML 是檢視與編修對照表，遊戲的正式資料來源是 JSON；直接修改匯出的 CSV 不會自動改動遊戲。

## 初階第 1 關（關卡 1）：個資小盾牌

**主題：個資守護**　只給任務需要的資料，密碼不交出去。

### 主要第1題　V2L01Q01

AI 想幫你找故事，哪一項和找故事沒有關係？

- A．喜歡冒險故事
- B．家裡的完整住址
- C．想看短一點的故事
- D．喜歡動物主角

**正確選項：B**

解析：只提供任務需要的資料。找故事可以用興趣，不用交出住址。

提示：想一想：找故事需要知道你住哪裡嗎？

各選項回饋：

- A：故事興趣可以幫忙推薦。
- B：答對！找故事不需要你家的住址。
- C：故事長度和找故事有關。
- D：主角喜好可以幫忙推薦。

來源：倫理延伸；教材單元 7、9、14、17，印刷 p65、79–84、149、173

### 主要第2題　V2L01Q02

- A．把密碼打進去

- C．不輸入，請大人幫忙看

解析：不把密碼交給聊天助手或陌生表單，有疑問就找可信任的大人。

- B：先處理密碼安全，貼圖數量不重要。
- C：答對！先保護密碼，再請可信任的大人協助。
- D：同學的密碼也要保護，不能代替自己的。

來源：倫理延伸；教材單元 7、9、14、17，印刷 p65、79–84、149、173

- C：刪掉原資料不能改變工程進度，也會失去核對線索。
- D：百分之百同樣是保證，仍然超出原資料能支持的說法。

### 綜合第15題　V3F14Q15

園遊會 AI 計畫要蒐集訪客姓名，材料費也超過預算。哪個修改最完整？

- A．只刪姓名，超支留給別人想辦法
- B．只減材料費，照樣要求每人留姓名
- C．讓 AI 保證不超支，就直接執行
- D．改用匿名人次，重算材料後請老師確認

**正確選項：D**

解析：AI 提供計畫後，人要檢查每個條件。用必要的匿名人次、核對材料預算，再請老師確認實際可行性。

提示：完整方案要一起處理哪些還沒解決的問題？

各選項回饋：

- A：少蒐集資料是一步，但材料費仍超過預算，需要一起處理。
- B：預算改善了，訪客姓名是否必要仍需檢查。
- C：口頭保證不能代替實際計算，也沒解決個資需求。
- D：答對！同時檢查資料用途與預算，再由人確認是否可執行。
