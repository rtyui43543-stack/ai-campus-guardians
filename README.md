# AI 校園守護隊 · 3D 對戰版

直接遊玩：[AI 校園守護隊](https://rtyui43543-stack.github.io/ai-campus-guardians/)

教師備課：[獨立教師手冊與題目答案](https://rtyui43543-stack.github.io/ai-campus-guardians/teacher/)。教師頁與學生遊戲分開，學生選單不顯示教師資料或答案下載。

給國小三至六年級的原創 AI 倫理答題遊戲。**初階與進階各六個主題關＋一個最終關，共十四關**。主題關各五題、最終關各十五題，共 **60 道主題＋30 道綜合題**。舊兩題重玩練習已移除入口，僅保留歷史紀錄查詢。兩條路線都以四個生活選項直接作答，不需要另選理由。

六個主題為個資守護、資訊查證、情境分類與合適使用、深偽查證、作業誠信，以及班級生活綜合應用。進階加入具體限制與另一位需要照顧的人，不增加艱深術語。

## GitHub Pages：下載一次後離線玩

首頁提供完整離線內容下載、檔案／容量／百分比進度、暫停與接續。學生第一次連網開啟網站、加入主畫面，再從圖示下載至「可離線使用」，之後沒有網路也能重開全部十四關、3D 動作與中文朗讀。學生不需要 GitHub 帳號或登入。

發布可選原始碼包（可維護題庫）或已建置的靜態網站包；兩者都支援 GitHub Pages 的 /儲存庫名稱/ 子路徑。原始碼包包含 .github/workflows/deploy-pages.yml 與預錄音檔，上傳後在 Settings → Pages 選 GitHub Actions。靜態包在 Pages 選 Deploy from a branch。使用 GitHub Desktop／git 推送解壓後的內容，不要只上傳 ZIP。

完整四步發布流程、手機／平板安裝方式與離線檢查見 [docs/github-pages.md](docs/github-pages.md)。本機產生兩種 GitHub 包：先 npm run build，再 npm run package:github；輸出在 release。日後更新時才需連網下載新版；清除網站資料或移除 App 可能刪除離線內容與進度，請先匯出備份。

## 從零重新冒險

「離線與設定」提供「全域進度重置」。先查看清除範圍，也能匯出備份；確認後清空兩組關卡進度、所有成績與作答紀錄、必殺收藏、提案和中途挑戰，回到封面，下一次開始重播開場故事。音效、音樂、難度與減少動態偏好會保留，已下載的離線內容不必重新下載。重置只影響這台裝置的遊戲進度，備份可從匯入功能還原。

逐題成績的問題、題號、作答方式與解說採較大字級；「我的成長」頂部統計以大數字、大標籤卡片呈現，手機換行保留閱讀空間。進階最終魔王使用九個可辨識龍頭的獨立透明素材，地圖、故事與對戰共用。

## Windows 直接玩

1. 完整解壓發佈包。
2. 雙擊「啟動遊戲.cmd」。發佈包已包含 Node.js，不需另行安裝。
3. 瀏覽器開啟 http://127.0.0.1:4173。保留服務視窗；結束時關閉或按 Ctrl+C。

3D 場景與魔法特效在本機運算；預先渲染的角色動作圖集、題庫、字型、中文朗讀與音效都在發佈包內，不需連接 AI 或登入。不能直接雙擊 dist/index.html 取代本機服務。

## 對戰方式

直接開啟遊戲網址或主畫面圖示，先看到原創 3D 風格封面，點「開始冒險」才進入遊戲。首次點擊會播放原創 3D 開場故事（四幕約 35 秒），之後進入關卡地圖；下次點開始可直接到地圖。有中途任務時，封面另提供「繼續上次挑戰」。封面下方仍可下載完整離線包，沒有側邊導覽或自動朗讀。冒險地圖不重複顯示下載檢查區，封面與「離線與設定」仍提供完整下載與更新功能。封面美術製作紀錄見 public/art/title-cover-provenance.md。

選擇任一關卡有三幕任務短劇（約 25 秒）。鏡頭切換校園全景、角色近景與服務問題，搭配主題動畫道具及大字幕。可暫停、換幕、略過至任務準備畫面，地圖「觀看開場故事」可重播。朗讀必須手動點選，朗讀時暫停換幕；減少動態模式改用靜態鏡頭與手動換幕。返回封面或關閉劇情不會取代中途存檔，按「開始對戰」才開始新挑戰。

題目、角色、血量與四個答案同在一個對戰畫面。男生角色小羽是原創校園魔法師，戴魔法帽、穿法袍，以法杖與施法手集氣。點答案立即判定，答對後施法，具體的城堡封印、書頁、拼圖、鏡刃、火羽或冰矛飛向敵方／展開，命中後扣血並顯示解說。每個主題都有自己的物件、動作與命中演出，不以共用光球換色當成新魔法。主題關敵方初始100HP，初階最終關200HP、進階最終關300HP；每題普通攻擊20HP，必殺另追加傷害。最終關魔王HP歸零時立即勝利，未作答的後續題不補成紀錄；最多15題結束時尚未擊敗魔王，則本場失敗。

地圖、劇情與對戰以封面美術為共同標準：小羽改用封面角色延伸製作的高精度透明動作圖集，保留棕色眼睛、臉型、層次棕髮、彎尖帽、布料與金邊細節。主角是預先渲染的 3D 風格角色（2.5D），以待機、集氣、施法和受擊四個姿勢搭配位移、鏡頭與魔法動畫；不是可任意旋轉的完整 3D 模型。初階魔王維持原有即時 3D 模型；進階使用六組獨立的高精度 3D 風格動作圖集，包含待機、集氣、施法和受擊。法陣與飛行法術仍由即時 3D 場景呈現，魔法起點依各姿勢的發射位置校準，發射後保持軌跡穩定。序章的金色機器人伙伴米米維持封面造型。關卡入口以播放圖示和大字「開始闖關」按鈕呈現，完成後顯示「再次挑戰」，下方保留關卡名稱、挑戰魔王與成績。

十二個主題關與兩個最終關共有十四位不同魔王，名稱、輪廓、地圖圖像、劇情及對戰一致；進階不以初階角色換色或復活重打。六個進階任務從個人的 AI 使用，擴展至分享、班級合作與更多人的需要。開場交代魔王來自使用服務時遇到的混亂，解決問題的目標仍是修復服務。

製作提示詞與素材校準紀錄見 public/art/advanced-bosses-provenance.md、public/art/hero-poses-provenance.md、public/art/courtyard-cover-provenance.md 與 public/art/boss-portraits-provenance.md；所有素材均納入離線包。劇情字幕與預錄語音同步更新；原六個主題關的題目、答案與教材來源維持原樣，最終關另有全新情境。必殺與進階限時玩法如下。

朗讀使用預製的台灣華語神經語音 zh-TW-HsiaoChenNeural，採成熟女聲、稍慢語速及清楚停頓；屬於合成語音。點題目、提示或解說旁的喇叭才朗讀，再點一次停止；新題目不自動朗讀，舊存檔也會套用這項調整。點「開始冒險」後，地圖、成長、提案與設定頁播放 PeriTune 的 EpicBattle_Deity；頂欄「音樂開／音樂關」可手動切換。初階與進階各六個主題關沿用 EpicBattle_Deity，兩個最終魔王關切換為 PeriTune 的 Fight3，音樂不疊播；對戰題目旁也有音樂開關，共用本機偏好。封面、故事及切到背景時暫停，若瀏覽器阻擋播放，可點「音樂關」啟播。音樂、出招音效與朗讀分別控制，朗讀時背景配樂降低音量。全部朗讀與兩首配樂包含在完整離線下載內。原始 MP3 未修改，署名與 CC BY 4.0 連結放在封面及主頁頁尾可展開的「音樂來源」。主角六種元素與不同魔王的普通攻擊、必殺、格擋及閃避使用對應的離線合成音效，配合蓄力、發射與命中；普通攻擊另加強元素尾跡、命中碎片及局部衝擊圈，減少動態設定仍保留較簡潔的呈現。

主題關答錯我方扣 12 HP；最終關基本扣 20 HP，連續自己答錯兩次起觸發魔王追擊必殺，每次額外扣 10 HP，合計上限 30 HP，答對後中斷連錯。超時扣基本傷害並中斷連錯，不觸發連錯追擊。血量最低為 0 HP；城堡護盾每次抵擋 12 HP，超過部分仍扣血。歸零後本次挑戰結束，不能繼續作答或請伙伴示範，也不會被持續回血復活；可重新挑戰同關，從第一題、100 HP、0 能量開始，已完成關卡、既有學習紀錄及已解鎖收藏卡會保留。血量尚未歸零時可提示、重試或請伙伴示範。初階不限時；進階主題關與最終關每題30秒。示範會協助出招，該題記為「看示範後完成」、0 分，不累積能量或觸發必殺。

主題關基本分滿分 100，五題各最高 20 分。每答錯一次，該題扣 4 分，自己答對至少得 4 分；用過提示的題目最高 16 分，伙伴示範完成得 0 分。初階不因速度扣分，剩餘血量也不影響分數。最終關的基本分按實際已完成題數換算為100分，詳見下方。進階主要題另套用時間上限：10 秒內（含）最高 20 分、20 秒內（含）最高 16 分、20 秒後至倒數歸零前最高 12 分；30 秒歸零時為超時、0 分。答錯、提示與時間三種上限取較低值，不重複扣提示分。例如先錯一次、用提示後在第 18 秒答對，該題得 16 分；第 25 秒才答對則 12 分。全部首次獨立答對、未用提示或示範，且每題取得基本滿分，才顯示「首次全對，滿分過關」。

- 主要挑戰答對一題累積 1 能量；答錯保留已累積的能量，進階超時仍扣 1 點，最低 0。只看目前能量，不另算連對次數，也不要求答錯後從頭連對三題。使用提示後自己答對仍累積能量；伙伴示範不累積。
- 能量累積到 3 點後準備必殺；**下一題自己答對時**小羽自動施放，不在取得第三點的當題施放。準備後答錯仍保留 3 點，重試答對即可施放；超時才降為 2 點，需要重新補到 3 點後，再一次答對才施放。
- 施放消耗 3 點、能量歸 0；每次必殺另獲 **10 點獎勵分**。基本答題分、必殺獎勵、總分分開顯示，例如基本 100＋必殺 10＝總分 110；獎勵不改寫基本分與逐題理解紀錄。
- 開始新關或重新挑戰時能量、守護盾皆歸 0；同一場中途回首頁或離開後續玩，保留能量、盾與剩餘答題時間。能量不能帶到下一關。舊複習題不提供新場次，僅保留歷史文字與成績。
- 實際施放必殺即可解鎖該主題、該等級的專屬收藏卡：初階 Lv.1 與進階 Lv.2 分開收集，共十二張。進階可直接挑戰，不必先獲得初階卡。在「我的成長」切換等級，查看升級來源與新卡圖；下載的 PNG 包含插畫及名牌文字，文字採卡圖座標置中，不隨視窗跑出框。已解鎖的卡不因戰敗或重來消失，解鎖紀錄納入備份；十二張圖檔均納入離線包。舊存檔依真實施放紀錄補回已獲得的不同等級卡，不依分數或通關紀錄推算。

初階攻擊與城堡必殺依「召喚蓄力 → 向魔王施放 → 命中與擴散」順序演出，城堡先展開護盾再攻擊。兩級必殺演出約三秒，顯示於題目與操作區下方，保留閱讀與按鈕的清晰度；減少動畫模式保留靜態形態並縮短演出。進階卡圖使用同一個封面角色參考，製作提示詞見 public/art/ultimate-advanced-provenance.md 與 public/art/ultimate-ice-provenance.md。初階城堡仍擋一次 12 HP，初階萬葉仍恢復 12 HP；舊成績與既有施放紀錄保留當時效果，不回溯重算。額外 HP 傷害與每次必殺獎勵的 10 分分開計算。兩級第六主題收藏改呈現寒冰系列。

| 雷霆 | 下一題兩個答案外框發出雷光，至少一個是答案；不扣提示分 |
| 鏡界 | 對方下次攻擊有 50% 機率落空，只判定一次；續玩保留已判定結果 |
| 寒冰 | 對方下次命中攻擊的傷害減半 |
| 回復 | 先恢復初階 12／進階 24 HP，後續每題完成再補 4 HP，最高 100 HP |

一題完成（答對、示範或超時）算一回合；燃燒和持續回血從施放的下一題開始，同題重試不重複結算，重複施放不疊加。鏡界先判定落空，命中才消耗寒冰與城堡；寒冰減半後，再扣城堡抵擋的 12 HP。回到同場保留狀態，開始新關或重新挑戰則重設。

每道主要題有自己的 30 秒作答時間；答錯後按「再試一次」沿用該題剩餘時間，不重新獲得 30 秒。超時時魔王攻擊扣基本傷害（主題關 12 HP、最終關 20 HP；再計算鏡界、寒冰與城堡），能量扣 1 點、該題 0 分；演出後自動進到下一題，不讓學生用延遲點擊補答。若這次攻擊使 HP 歸零，則進入戰敗與重新挑戰。

解說／錯誤回饋、規則說明、回到首頁、離開對戰及頁面切到背景時，倒數暫停；重新進入同場挑戰才從剩餘時間繼續。每次進入新題才重設 30 秒。包含超時的整場完成後仍保留成績、逐題紀錄及必殺收藏，但本次標示「尚未通關」，需重新挑戰並完成所有題目才能通關；不會抹去過去已通過的同關紀錄。

對戰即時顯示基本分、必殺獎勵與能量，結算列出每題分數、真實答錯次數、提示、示範、時間與超時紀錄。「我的成長」保留主題關、最終關與舊複習的歷史成績，點一筆可回看逐題回答，並查看／下載已解鎖必殺收藏；關卡卡片顯示主題挑戰的最高基本分、最近得分與挑戰次數。舊版只有完整且依序的回答紀錄會換算基本分，不追溯扣時間分或補發必殺獎勵；示範題若無法確定實際答錯次數，會標示舊紀錄次數不明。未完成的舊紀錄不推算成績。文字與狀態改用深色，主要內文 18px、輔助說明 16px，手機內文至少 16px。

對戰左上角、戰敗畫面與其他頁面提供「回到首頁」按鈕，可返回遊戲封面並保留目前任務；返回封面會停止朗讀與配樂。地圖可自由選關、暫存途中任務。網址的 #cover 為封面；#map、#battle、#growth、#proposals、#settings 可直接開啟對應頁面，瀏覽器上一頁／下一頁也會切換畫面。沒有可還原存檔的對戰或結算連結會回到封面。初階與進階各有獨立題目。完成進階第六關會產生「我的 AI 使用約定」卡，可補充反思、匯出或列印。

### 最終守護戰

每條路線新增一個最終關：初階第13關「混沌魔典王」、進階第14關「幻象九頭龍」。必須集齊同等級六張必殺卡，才可開啟該等級最終關；看目前實際收藏，不以通關分數或另一等級的卡代替。

初階最終魔王200HP、進階最終魔王300HP；我方100HP，各有十五道全新生活情境的綜合挑戰，涵蓋六種生活主題；不重複前六關題目，也不使用被移除的複習題。答對普通攻擊20HP；必殺照既有等級效果追加傷害、防禦或恢復。魔王HP歸零立即勝利，可提前結算；十五題用盡仍有魔王HP則本次失敗。已實際完成的題目、時間、施放與分數保存，不造出未回答的紀錄。

最終基本分＝已完成題目原始分總和÷（實際完成題數×20）×100，取兩位小數；提前勝利後未出現的題目不列入分母，已超時的題目仍計入且得0分。每次必殺另加10點獎勵，初階最多兩次、最高總分120；進階最多三次、最高總分130。初階不限時，進階每題30秒；最終關曾超時仍可繼續，只要擊敗魔王即可勝利，不沿用主題關「包含超時即尚未通關」的條件。

兩個最終關各有三幕獨立導入，接續六種魔法已匯聚的設定。故事原文與十四關對照見[docs/故事大綱與關卡劇情.md](docs/故事大綱與關卡劇情.md)。目前沒有各關修復收尾動畫或全校結局動畫，不把這些尚未實作的內容當作既有劇情。

### 我的成長儀表板

闖關成績改用大字統計、六大主題的最高答題分進度條、最近八次答題分趨勢及回答方式環形圖呈現。可切換全部闖關、初階、進階與歷史複習；現行挑戰與歷史複習分開統計。圖表固定使用 0–100 答題分，必殺獎勵另列，總分可超過 100。回答方式以各關最近一次紀錄計算，分為首次自己答對、提示或重試後答對、伙伴示範與超時，不因重複闖同一關膨脹題數。

全部挑戰紀錄預設收合，展開後每頁六張大字成績卡。點主題成績條、趨勢分數或紀錄卡可查看原有逐題得分；尚未挑戰的關卡提供闖關入口。無紀錄與實際零分分開顯示，既有進度、計分與必殺收藏保持原樣。儀表板使用本機資料與 SVG 圖表，不需要外部圖表服務，完整離線下載後也可查看。

## 離線與備份

Windows 發佈包透過本機服務可直接在斷網環境使用。在手機／平板使用 PWA 時，先經 HTTPS 開啟，於首頁或「離線與設定」下載完整離線包，完成檢查後才能斷網重新開啟並播放朗讀。PWA 不支援一般區域網路 HTTP 網址；手機與平板仍須實機驗收。

進度只存在這台裝置，可匯出與還原 JSON。新版十四關沿用獨立v2存檔空間，保留舊十八關 v1 資料；舊備份不會被套到新題目。清除網站資料會移除進度與離線包，請先匯出備份。新版完整下載後才能套用，避免更新到一半缺少素材。

## 題庫與答案

「docs/題庫與答案」附完整 CSV、Markdown、可列印 HTML 與原始 JSON；獨立教師備課網址 /teacher/ 提供手冊、關卡對照及檔案下載。每題包含 A–D 選項、正確選項、解析、提示、難度、主題／最終關標記與教材對照。教師網址是公開頁面，與學生遊戲分開呈現；teacher/ 目錄不加入學生離線包，教師可另行下載備課檔案。

現行題庫來源為src/content/question-bank.json，包含90道正式題。舊24道複習封存在src/content/legacy-review-bank.json，舊30道最終題封存在src/content/legacy-final-bank.json，只供既有存檔lookup，不列入現行教師匯出或新的闖關。新最終題的themeId保留六大主題對照，每題為獨立新情境，使用V3F前綴避免覆寫舊答案。correct 是從 0 起算的選項索引：0=A、1=B、2=C、3=D；多個合理答案可列在同一陣列。CSV 供檢視／核對，不會自動匯回遊戲。修改 JSON 後須重新匯出答案、生成朗讀與建置；具體方式見題庫資料夾的修改說明。學生端使用本機規則判題，不使用生成式 AI 判分。

## 修改原始碼

需要 Node.js 24、npm 與套件依賴：

    npm ci
    npm run questions:export
    npm run teacher:export
    npm run audio:manifest
    npm run audio:generate
    npm run content:check
    npm test
    npm run build

只在題目文字或語音設定改動時重新生成朗讀。新版生成流程使用 Python、edge-tts 與 FFmpeg，製作時需連網；可用 AI_GAME_FFMPEG 指定 FFmpeg 路徑。語音設定與可重製步驟見 [docs/audio-notes.md](docs/audio-notes.md)。一般遊玩和 GitHub 建置直接使用已預錄的 MP3，不需要這些工具、語音帳號或線上 API。重新生成後再執行內容檢查。介面開發可用 npm run dev；PWA 驗收使用建置版。Windows 打包執行 scripts/package-windows.ps1；GitHub 原始碼與靜態網站打包執行 npm run package:github。

npm run build 會先重新匯出教師手冊與答案，再建置學生遊戲。封面插畫、字型與所有素材隨離線包儲存；魔法校園主題以本機 CSS 製作星圖、法陣與任務色彩，沒有外部圖片或 CDN 的執行依賴。保留大字、高對比卡片與原有 3D 戰鬥，關卡地圖的冒險總覽顯示已完成關卡、掌握魔法及主要挑戰最高分。
