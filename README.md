# AI 校園守護隊 · 3D 對戰版

直接遊玩：[AI 校園守護隊](https://rtyui43543-stack.github.io/ai-campus-guardians/)

教師備課：[獨立教師手冊與題目答案](https://rtyui43543-stack.github.io/ai-campus-guardians/teacher/)。教師頁與學生遊戲分開，學生選單不顯示教師資料或答案下載。

給國小三至六年級的原創 AI 倫理答題遊戲。**初階六關＋進階六關，共十二關**。每關五道主題與兩道重玩練習，共 **60 道主題＋24 道練習**。兩條路線都以四個生活選項直接作答，不需要另選理由。

六個主題為個資守護、資訊查證、情境分類與合適使用、深偽查證、作業誠信，以及班級生活綜合應用。進階加入具體限制與另一位需要照顧的人，不增加艱深術語。

## GitHub Pages：下載一次後離線玩

首頁提供完整離線內容下載、檔案／容量／百分比進度、暫停與接續。學生第一次連網開啟網站、加入主畫面，再從圖示下載至「可離線使用」，之後沒有網路也能重開全部十二關、3D 動作與中文朗讀。學生不需要 GitHub 帳號或登入。

發布可選原始碼包（可維護題庫）或已建置的靜態網站包；兩者都支援 GitHub Pages 的 /儲存庫名稱/ 子路徑。原始碼包包含 .github/workflows/deploy-pages.yml 與預錄音檔，上傳後在 Settings → Pages 選 GitHub Actions。靜態包在 Pages 選 Deploy from a branch。使用 GitHub Desktop／git 推送解壓後的內容，不要只上傳 ZIP。

完整四步發布流程、手機／平板安裝方式與離線檢查見 [docs/github-pages.md](docs/github-pages.md)。本機產生兩種 GitHub 包：先 npm run build，再 npm run package:github；輸出在 release。日後更新時才需連網下載新版；清除網站資料或移除 App 可能刪除離線內容與進度，請先匯出備份。

## Windows 直接玩

1. 完整解壓發佈包。
2. 雙擊「啟動遊戲.cmd」。發佈包已包含 Node.js，不需另行安裝。
3. 瀏覽器開啟 http://127.0.0.1:4173。保留服務視窗；結束時關閉或按 Ctrl+C。

所有 3D 模型由程式在本機建立；題庫、字型、中文朗讀與音效都在發佈包內，不需連接 AI 或登入。不能直接雙擊 dist/index.html 取代本機服務。

## 對戰方式

首次從首頁進入會播放原創 3D 開場故事（四幕約 35 秒），選擇任一關卡則有三幕任務短劇（約 25 秒）。鏡頭切換校園全景、角色近景與服務問題，搭配主題動畫道具及大字幕。可暫停、換幕、略過至任務準備畫面，首頁「觀看開場故事」可重播。朗讀必須手動點選，朗讀時暫停換幕；減少動態模式改用靜態鏡頭與手動換幕。返回首頁或關閉劇情不會取代中途存檔，按「開始對戰」才開始新挑戰。

題目、角色、血量與四個答案同在一個對戰畫面。男生角色小羽是原創校園魔法師，戴魔法帽、穿法袍，以法杖與施法手集氣。點答案立即判定，答對後施法，魔法飛向敵方，命中後扣血並顯示解說。六個主題有不同法陣、光跡與命中特效。敵方初始 100 HP，每道主題扣 20 HP，五題完成；重玩練習每題扣 50 HP。

朗讀使用預製的台灣華語神經語音 zh-TW-HsiaoChenNeural，採成熟女聲、稍慢語速及清楚停頓；屬於合成語音。點題目、提示或解說旁的喇叭才朗讀，再點一次停止；新題目不自動朗讀，舊存檔也會套用這項調整。對戰時播放原創節奏配樂，題目旁的「音樂開／音樂關」可隨時切換，設定會保存在本機；離開對戰或切到背景時暫停。音樂、出招音效與朗讀分別控制，朗讀時背景配樂降低音量。全部朗讀與配樂包含在完整離線下載內。

答錯我方扣 12 HP，血量最低為 0 HP。歸零後本次挑戰結束，不能繼續作答或請伙伴示範；可重新挑戰同關，從第一題與 100 HP 開始，已完成關卡和既有學習紀錄會保留。血量尚未歸零時可提示、重試或請伙伴示範。沒有倒數。示範會協助出招，並記為「看示範後完成」。

每關滿分 100 分，五題各 20 分。每答錯一次扣 4 分，自己答對至少得 4 分；用過提示的題目最高 16 分，伙伴示範完成的題目得 0 分。兩題重玩練習則各 50 分、答錯扣 10 分、最低 10 分、提示最高 40 分。全部首次獨立答對、未用提示或示範，會顯示「首次全對，滿分過關」。答題速度和剩餘血量不影響分數。

對戰即時顯示目前得分，結算列出每題分數、真實答錯次數、提示與示範。「我的成長」保留每次完整挑戰及重玩成績，點一筆可回看逐題回答；關卡卡片顯示主題挑戰的最高分、最近得分與挑戰次數。舊版只有完整且依序的回答紀錄會換算分數；示範題若無法確定實際答錯次數，會標示舊紀錄次數不明。未完成的舊紀錄不推算成績。文字與狀態改用深色，主要內文 18px、輔助說明 16px，手機內文至少 16px。

對戰左上角、戰敗畫面與其他頁面提供「回到首頁」按鈕，可返回首頁關卡地圖並保留目前任務；離開對戰會停止朗讀與配樂。地圖可自由選關、暫存途中任務。初階與進階各有獨立題目。完成進階第六關會產生「我的 AI 使用約定」卡，可補充反思、匯出或列印。

## 離線與備份

Windows 發佈包透過本機服務可直接在斷網環境使用。在手機／平板使用 PWA 時，先經 HTTPS 開啟，於首頁或「離線與設定」下載完整離線包，完成檢查後才能斷網重新開啟並播放朗讀。PWA 不支援一般區域網路 HTTP 網址；手機與平板仍須實機驗收。

進度只存在這台裝置，可匯出與還原 JSON。新版十二關採獨立 v2 存檔空間，保留舊十八關 v1 資料；舊備份不會被套到新題目。清除網站資料會移除進度與離線包，請先匯出備份。新版完整下載後才能套用，避免更新到一半缺少素材。

## 題庫與答案

「docs/題庫與答案」附完整 CSV、Markdown、可列印 HTML 與原始 JSON；獨立教師備課網址 /teacher/ 提供手冊、關卡對照及檔案下載。每題包含 A–D 選項、正確選項、解析、提示、難度、主題／練習標記與教材對照。教師網址是公開頁面，與學生遊戲分開呈現；teacher/ 目錄不加入學生離線包，教師可另行下載備課檔案。

唯一題庫來源為 src/content/question-bank.json。correct 是從 0 起算的選項索引：0=A、1=B、2=C、3=D；多個合理答案可列在同一陣列。CSV 供檢視／核對，不會自動匯回遊戲。修改 JSON 後須重新匯出答案、生成朗讀與建置；具體方式見題庫資料夾的修改說明。學生端使用本機規則判題，不使用生成式 AI 判分。

## 修改原始碼

需要 Node.js 24、npm 與套件依賴：

    npm ci
    npm run questions:export
    npm run teacher:export
    npm run audio:manifest
    npm run audio:generate
    npm run content:check
    npm test
    npm run build

只在題目文字或語音設定改動時重新生成朗讀。新版生成流程使用 Python、edge-tts 與 FFmpeg，製作時需連網；可用 AI_GAME_FFMPEG 指定 FFmpeg 路徑。語音設定與可重製步驟見 [docs/audio-notes.md](docs/audio-notes.md)。一般遊玩和 GitHub 建置直接使用已預錄的 MP3，不需要這些工具、語音帳號或線上 API。重新生成後再執行內容檢查。介面開發可用 npm run dev；PWA 驗收使用建置版。Windows 打包執行 scripts/package-windows.ps1；GitHub 原始碼與靜態網站打包執行 npm run package:github。

npm run build 會先重新匯出教師手冊與答案，再建置學生遊戲。魔法校園主題以本機 CSS 製作星圖、法陣與任務色彩，不依賴外部圖片或 CDN；保留大字、高對比卡片與原有 3D 戰鬥。首頁冒險總覽顯示已完成關卡、掌握魔法及主要挑戰最高分。

## 來源與實作

教材《生活中的人工智慧》（臺北市國小人工智慧教材，2020）提供辨識、分類、人機協作與學習應用的知識基礎。個資、公平、人類查核、深偽與作業誠信另標示為倫理延伸。印刷頁碼與 PDF 頁碼差一頁。影片與截圖只作為配置及 Q 版比例參考，角色、場景與招式均重新設計，未使用參考作品模型。

React＋TypeScript＋Three.js 即時 3D、版本化規則題庫、IndexedDB／localStorage 存檔、SHA-256 校驗的 Service Worker 離線包。3D 需要支援 WebGL2 的瀏覽器；若裝置無法建立 3D 畫面，會顯示說明，不以靜態圖冒充 3D。

Windows 包附 Node.js 24.18.1 與授權文件；軟體／字型聲明見 dist/THIRD_PARTY_NOTICES.txt。驗收證據與待完成的學生、實機試玩見 docs/acceptance.md。
